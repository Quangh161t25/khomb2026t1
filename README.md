# Hệ Thống Quản Trị Kho Vận 2026 - React Edition

Ứng dụng quản trị kho vận, đơn hàng và đối soát kết nối Google Sheets.

## Cấu trúc thư mục
- `public/`: Chứa file tĩnh và ảnh.
- `src/assets/`: Chứa hình ảnh và icons nội bộ.
- `src/components/`: Chứa các UI components dùng chung.
- `src/pages/`: Chứa toàn bộ các trang giao diện chức năng.
- `src/layouts/`: Chứa MainLayout, Header, Sidebar, Footer.
- `src/services/`: Chứa dịch vụ gọi API và xuất Excel.
- `src/hooks/`: Chứa custom React hooks.
- `src/utils/`: Chứa các hàm tiện ích (ngày tháng, tìm kiếm, định dạng).
- `src/context/`: Quản lý xác thực và thông báo (Toast).
- `src/config/`: Cấu hình Google Sheets và hệ thống.

## Cài đặt & Khởi chạy
```bash
npm install
npm run dev
```
